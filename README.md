## 🛠️ Troubleshooting Common Issues  

### ❌ The Theme Didn't Apply  

If you still see the default boot screen:  
- Make sure you **ran the installer as administrator**.  
- Try **restarting your computer fully** (not just shutdown/start, but restart).  
- Check that your Windows version supports GRUB2 themes (it works on most modern versions).  

### ❌ "Access Denied" or Error Messages  

- Close all other programs and try again.  
- Temporarily disable antivirus software, then re-run the installer.  
- Ensure you have at least 50 MB of free disk space.  

### ❌ The Boot Menu Looks Blurry  

This usually happens on low-resolution displays. Adjust the resolution in the configuration file (see above) by setting a lower value like `1024x768`.
